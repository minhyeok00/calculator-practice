# Swift UI-Calculator Practice
> **강의 실습: 찬우와 함께 만든 UIKit 기반 계산기**

## 📝 프로젝트 개요
iOS 프로그래밍 수업 중 실습으로 제작한 계산기 앱입니다. 
단순히 기능을 구현하는 것을 넘어, **Auto Layout**과 **Stack View**를 활용해 다양한 기기 화면에서도 UI가 깨지지 않도록 설계하는 연습을 했습니다.

## 🤝 협업 및 배운 점
- **동료와 함께:** 페어 프로그래밍을 진행하며, 버튼 배치(UI)와 계산 로직(Swift)을 나누어 작업했습니다.
- **UI 최적화:** 가로/세로 Stack View를 중첩해서 사용하여 실제 계산기 같은 버튼 배열을 완성했습니다.
- **연산 처리:** `IBAction`을 통해 입력받은 숫자를 처리하고 사칙연산을 수행하는 기초적인 로직을 익혔습니다.

## ⚙️ 주요 기능
- **Basic Ops:** 더하기, 빼기, 곱하기, 나누기 사칙연산
- **Clear:** AC 버튼을 이용한 입력값 초기화
- **Layout:** Stack View 기반의 균형 잡힌 UI 디자인

- **한성대학교 소프트웨어 공학
